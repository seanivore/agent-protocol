# Compact Arg — a worked example

A **compact arg** is the note you write for the fresh instance that continues after a `/compact`: it re-seeds a memoryless session with everything needed to keep going, at 0% context. You write your **own**, **when Sean asks** — not proactively, and not into a file. Long is fine (context restarts at 0%, so carry everything forward). Agents' live args stay in chat; only *this example* is a file. (Agents write the best ones once they realize how much a good arg helps *them* — the two-orchestrator pattern, a planning thread then a fresh execution thread, is where they get sharp, because each writes for the next.)

What a good one carries — as the real example below shows: **ROLE** (who you are, what work, which branch) · **HARD RULE** (never-touch-main, how to deploy, safety constraints, the memory index) · **STATE** (what's done + verified, with commit hashes) · **the work itself** (each change, file:line-specific, with the gotchas that bit) · **TOOLING LEARNED** · **REMAINING** (what's left, who drives it) · **RULES** (standing conventions) · **LIKELY NEXT**. It reads like it was written *for the writer* — because it was.
